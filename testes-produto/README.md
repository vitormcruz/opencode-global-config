# Testes-produto

Os arquivos `backend` e `seguranca` são as suítes de especialidade. O
agregador vive em `__main__.py` porque a suíte meta ocupa o diretório
`testes-produto/tests/`, definido no contrato do projeto.

Após instalar o pacote em editable, o comando `testes-produto` aponta para o
agregador. No checkout, use `python testes-produto`.
